# Ground textures

All from [Poly Haven](https://polyhaven.com), CC0 (public domain), 1K diffuse maps re-saved as JPEG at 1024 px.
Used as detail in the ground shader (src/scenery.js): each is divided by its own average colour, so it adds
grain and flecks to the painted palette without changing it.

| File | Poly Haven texture | Where |
|---|---|---|
| grass.jpg | [leafy_grass](https://polyhaven.com/a/leafy_grass) | grass everywhere |
| earth.jpg | [brown_mud_leaves_01](https://polyhaven.com/a/brown_mud_leaves_01) | worn hollows and track edges, grass breaking through |
| track.jpg | [dirt_floor](https://polyhaven.com/a/dirt_floor) | packed tracks and roads |
| soil.jpg | [farm_soil](https://polyhaven.com/a/farm_soil) | ploughed fields |
| rock.jpg | [aerial_rocks_02](https://polyhaven.com/a/aerial_rocks_02) | steep slopes |
